🚀 Flask Learning Project

This repository is created to learn and improve Flask step by step.
The goal of this project is to understand how to build web applications using Python and Flask while gradually adding new features and concepts.

📌 Purpose

Learn Flask fundamentals

Practice backend web development

Build small features step by step

Understand how web applications work

🛠 Technologies Used

Python

Flask

HTML

CSS

Git & GitHub

📚 Learning Roadmap

This project will improve over time as new Flask concepts are learned.

Step 1 – Basic Flask App

Create a simple Flask server

Run a local web application

Step 2 – Routing

Create multiple routes

Handle URLs

Step 3 – Templates

Use Jinja2 templates

Connect HTML with Flask

Step 4 – Static Files

Add CSS and JavaScript

Serve static assets

Step 5 – Forms

Handle user input

Process form data

Step 6 – Database

Connect database (SQLite / MySQL)

Store and retrieve data

Step 7 – Authentication

Login and registration system
